## 国内要求和海外是否一致

**大方向一致**

1. **评测是两边共同的核心门槛**:国内 56%、海外 62% 的 JD 提评测。腾讯 Agent Harness 岗要求「每次 Prompt、模型、工具变更都有量化的收益与回归判定」;智联上一家郑州公司要求「能讲清上线后效果指标是多少、是怎么测出来的」;LangChain、Harvey、Cohere 都把能用评测驱动质量写进要求。
2. **Python 为主**(国内 65%、海外 63%),RAG 两边都过半(52% / 54%),部署和工程化两边都要。
3. **真实上线经验比框架名重要**:海外几乎每条写「shipped to production」;国内大厂写「全链路交付」,中小公司写「至少 1 个已上线的大模型应用项目,本人承担主要开发」。
4. **熟练用 Coding Agent 已经是显式要求**:国内 26%、海外 15%(Boss A/D/G、腾讯 Harness 岗、V2EX 远程兼职岗都点名 Claude Code/Codex/Cursor;海外 OpenAI Codex 系列、Cognition、Cohere Agent Code)。这一条国内反而比海外写得更多。

**明显不同**

1. **国内更看重 Agent 内部机制,海外更看重结果和交付**(第二批补进来后差距缩小):国内合计上下文工程 52% vs 海外 25%、多 Agent 37% vs 22%、工具调用 55% vs 39%、Skills 10% vs 3%;MCP 合计 17% 和海外 16% 持平(第一批只看大厂时是 26%)。第一批大厂官网样本的比例更高(上下文工程 66%、多 Agent 42%);腾讯、美团、百度、字节多个岗位标题直接写「Agent Harness」「Agent Infra」。海外 JD 更抽象,强调 ownership、和客户一起把 agent 落地。
2. **海外面向客户的岗位多**:Forward Deployed Engineer、Applied AI Architect、Agent Deployment Engineer 在美国本土样本里占一半以上(面向客户 52%);国内对应的是「对接业务部门」,很少要求对外面向客户。国内也开始出现 FDE 岗(智联上 2 条、百度数字人 FDE)。
3. **门槛结构**:国内主流 3–5 年(Boss 31.5%、猎聘 43.6%),明确卡硕士的约一成(Boss 列表硕士+博士 9.4%、猎聘 12.1%);海外年限中位 5 年(美国 Staff 岗 8 年以上),学历基本不提。
4. **语言栈**:国内 Go(34%)、Java(24%)明显多;海外 TypeScript 更多(美国本土 45%)。
5. **国内特有信号**:Skills 体系、Agent Harness、Agent 经济学/ROI(Boss G)、Computer/Browser Use(Boss G、腾讯浏览器自动化岗)、对接企业审批和协作工具 + SQL(Boss D)、OpenTelemetry(Boss F、腾讯可观测岗)。其中 Skills 在海外样本里只有 Anthropic 和新加坡几家外包写到,Harness 只有 HN 上 Tether 一条。
6. **新加坡/香港介于两者之间**:技术栈清单式要求最多(RAG 84%、Prompt 71%、向量库 52%、SQL 64%),偏企业落地和金融行业;香港岗位集中在金融、加密货币公司(OKX、Binance、Amber、RedotPay、Bullish、CoinDesk)和咨询公司。
7. **薪资差距**:国内(Boss + 猎聘 557 条)挂牌年包中位 48 万人民币(P25 36 万、P75 68 万,万人以上公司中位 57 万);新加坡中位约 9–12 万新币/年(多为中介外包岗);美国本土中位 $200K–$335K;海外远程能拿美国 band 的岗位基本都限美加身份。

## 局限

国内第一批 120 条里大厂官网 74 条、智联 27 条、Boss 截图 7 条,大厂官网没有薪资。第二批 Boss 435 条只有 74 条有正文(账号被提示异常后停止),技能比例里 Boss 的代表性有限;Boss 和猎聘每个「关键词 × 城市」只抓了第 1 页,排序受平台推荐算法和站长账号画像影响;两批打标正则不同(第二批校准误差见上)。拉勾、51job 仍未抓到。国内薪资是挂牌区间中点,不是成交价。海外 LinkedIn 只抓到前 30 条搜索结果,HN 偏创业公司。技能比例是关键词匹配,只用来看方向。
